This runs on the network: your text goes from worker to worker, one hop per block for every byte, and you can watch which worker ran each hop. If no worker holds a block, the coordinator runs that hop and says so. It is a small experimental model, not a chatbot, and output may be incoherent.

Do not enter private information or secrets. Your text is sent to participants' computers as well as the coordinator.

Contribute compute

Join with one command

No account and nobody to ask. Your worker gets its own credential, trains one block at a time and serves that block for network inference. A GPU is optional. Contributions use compute, power and bandwidth.

  1. On Linux or macOS, run the command. It installs what it needs in ~/dbmoe-worker and starts.
  2. On Windows, or to set it up by hand, use the second set of commands.
  3. Leave it running as long as you like. Stop it with Ctrl+C and start it again whenever you want; it keeps its credential.
  4. Leaving for good? Run the leave command: your workers come off the list and your credential ends. What you already contributed stays in the model. You can rejoin at any time.

The coordinator checks incoming updates before merging them. Follow accepted work and model evaluations above. Want your own token first? Run enrol: it is optional, and the worker does this by itself. Keep credentials out of GitHub, screenshots and public messages. Use --no-serve to train without serving inference.

Worker source and setup guide on GitHub

# Linux or macOS
curl -fsSL https://codex.opentransformers.online/dbmoe/join.sh | sh

# Windows, or by hand (Windows: py instead of python3, curl.exe in PowerShell)
python3 -m pip install torch --index-url https://download.pytorch.org/whl/cpu
curl -fsSL https://codex.opentransformers.online/dbmoe/code -o dbmoe.py
python3 dbmoe.py worker

# Options: --device cuda  --threads 4  --hours 1  --no-serve
# Optional, your own token first: python3 dbmoe.py enrol

# Leaving for good: takes you off the worker list
curl -fsSL https://codex.opentransformers.online/dbmoe/leave.sh | sh

Use only computers you own or are authorized to use. Source and setup guide: GitHub repository.

Enrolment happens directly between your terminal and the coordinator. This dashboard does not collect tokens or register workers.

Use one identity across several machines

After installing the worker, create one contributor token. Copy its file securely to the other computers you own or are authorised to use. Start each machine with a different worker name; their contributions share the same identity.

# Create the shared identity once
python3 dbmoe.py enrol --token-file contributor.token

# On each machine, use its own name
python3 dbmoe.py worker --token @contributor.token --name machine-01

Keep contributor.token private. Change machine-01 for each computer. To join anonymously with a separate identity, use the normal worker command above; no account is needed.
